# pick_me_captcha

캐릭터/인물 이미지를 넣어 커스텀 CAPTCHA 스타일 이미지를 만들고 저장할 수 있는 브라우저 기반 미니 웹툴입니다.

## 주요 기능
- 2x2 / 3x2 / 3x3 레이아웃 선택
- 사진 개별 업로드
- 사진 위치/확대 조절
- 타일 순서 변경
- 큰 타이틀 / 상세 문구 편집
- 체크 아이콘 스타일 선택
- 커스텀 헤더 컬러 선택
- PNG / JPEG 저장
- 모바일 반응형 미리보기

## GitHub Pages 배포
1. 이 폴더의 `index.html`, `README.md`, `.nojekyll`을 저장소 루트에 업로드합니다.
2. GitHub 저장소에서 `Settings` > `Pages`로 이동합니다.
3. `Deploy from a branch`를 선택합니다.
4. Branch는 `main`, Folder는 `/(root)`로 선택 후 저장합니다.

## Privacy
이미지는 서버나 데이터베이스에 저장하지 않고 브라우저 안에서만 처리됩니다.
